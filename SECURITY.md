# Security and Responsible Disclosure

This repository publishes research about security-sensitive engineering governance. Please do not open a public issue containing credentials, private keys, exploitable private-system details, or other secrets.

For research corrections that are not security-sensitive, a normal issue or pull request is appropriate.

For a suspected vulnerability in a CEOS implementation, use the security-reporting mechanism of the affected implementation repository rather than treating this research corpus as the operational security boundary.

Research descriptions of proposed controls must not be interpreted as evidence that those controls are deployed or non-bypassable in a live environment.
